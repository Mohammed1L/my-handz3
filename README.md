# 📱 Senior Project — Handz

A complete **Flutter + Firebase** mobile application developed as a senior project at  
**[King Fahd University of Petroleum and Minerals (KFUPM)](https://www.kfupm.edu.sa/)**.

---

## 🚀 Overview

**Handz** is a service-providing mobile platform built with **Flutter** and powered by **Firebase**. It connects users with skilled service providers, offering a seamless experience from booking to payment — all within a single app.

---

## ✨ Features

- 🔐 **Authenticated Login** — Secure sign-in with email/password via Firebase Authentication
- 📱 **OTP Verification** — Phone number verification using one-time passwords for added security
- 🗺️ **Google Maps Integration** — Browse and locate nearby service providers in real-time
- 💳 **Payment Integration** — In-app payment support for booking and paying service providers
- 🛠️ **Service Providing** — Users can list, discover, and book a wide variety of services
- 📡 **Real-time Data** — Live updates powered by Firebase Firestore
- 🔔 **Push Notifications** — Stay updated with Firebase Cloud Messaging
- 👤 **User Profiles** — Manage personal info, service history, and preferences

| Tool | Description |
|---|---|
| Flutter SDK | [Install from here](https://docs.flutter.dev/get-started/install) |
| IDE | Android Studio or Visual Studio Code |
| Device | Physical device or emulator/simulator |
| Firebase Access | Use provided config or set up your own project |

---

### 🔧 Setup Instructions

#### 1. Clone the Repository
```bash
git clone https://github.com/ramiAlmathani/Senior_Project_2.0.git
cd senior_project_2
```

#### 2. Install Dependencies
```bash
flutter pub get
```

#### 3. Run the App
```bash
flutter run
```
